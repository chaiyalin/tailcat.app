隐私说明 / Privacy notice

我们尽量不收集数据，但“端到端加密”不等于没有网络元数据。本页说明浏览器、Cloudflare、Tailcat DERP 与 WebRTC 各自会处理什么。

We try to collect as little data as possible, but end-to-end encryption does not eliminate network metadata. This notice explains what the browser, Cloudflare, Tailcat DERP, and WebRTC each process.

中文

1. 谁在提供服务

tailcat.app 是独立的非官方开源测试项目，不是 Tailscale Inc. 的产品，也未获得其关联或背书。隐私或滥用问题可联系 abuse@tailcat.app。

2. 本站不建立哪些数据

本站不要求账号，不建立用户档案，也没有用于保存文字、文件、语音留言、房间成员或聊天历史的服务端应用数据库。我们不提供离线投递、稍后从服务器下载、云端备份、内容恢复或病毒扫描。多人房间的成员状态和有限恢复缓冲只存在于房主浏览器内存中；浏览器接收符合条件的一对一文件时可能使用仅属于本站来源的私有临时存储，具体见第 6 节。

首版不加载第三方分析脚本、第三方字体或远程错误上报。Cloudflare Web Analytics 在公开测试版中关闭。多人房间诊断不得记录邀请、令牌、Tailcat 地址、昵称、消息、文件名、内容或 IP；若启用运行诊断，只允许匿名运行编号、成员数、时延、错误类别、字节数和资源计数。

3. 打开网页时

静态网页由 Cloudflare Pages 提供。为交付与保护网站，Cloudflare 会处理常见的 HTTP 和安全元数据，例如 IP 地址、时间、请求路径、User-Agent、TLS 与缓存信息。此类边缘日志和安全记录由 Cloudflare 按其服务配置与政策处理；本站不承诺可以访问、导出或逐条删除这些提供商记录。

一对一地址以及多人房间的临时房间编号和加入令牌放在 URL 的 #fragment 中。片段不会随常规 HTTP 请求发送给 Cloudflare Pages；应用会在读取邀请后立即从地址栏移除片段。但它在被移除前仍可能出现在浏览器历史、剪贴板、浏览器扩展、同步功能、截图或屏幕共享中。房主轮换多人邀请后，旧加入令牌失效，但已加入成员不会因此断开。

4. Tailcat 传输

文字、语音留言、控制和文件中继通道使用 Tailcat WireGuard。启用原生文件直传且双方支持时，文件正文优先使用可靠 WebRTC DataChannel 的 DTLS 加密，不经过 Go 网络栈；无法直连则使用 Tailcat/DERP。文件哈希仍通过逐块 JS/WASM 复制计算，并非零复制。群聊文字由可信房主读取、排序和转发；群组文件正文不经过房主浏览器。

文件直传也可能向对端暴露公网 IP，不申请摄像头或麦克风权限。中断后先查询保存结果，至多自动从头中继重传一次，不续传；无法确认时显示结果未确认，不自动创建第二份文件。未完成的 OPFS 文件先删除再用新随机名称创建；文件选择器重置未提交事务。已校验提交的文件不因回执丢失删除。完成回执只在会话内存保存，最多 256 条、30 分钟，结束房间即清除。

多人房主可看到昵称、随机成员短码、成员关系、群聊文字、文件大小和所选接收者，但不通过协调协议获得点对点文件名、语音内容或文件内容。任何实际接收者仍可保存、复制或转发其收到的内容。

浏览器版目前使用公共 Tailcat DERP 中继。中继无法读取其承载的加密内容，但会处理或观察通信端点 IP、连接时间、DERP 区域、数据量与流量模式等元数据。公共 DERP 限速、尽力而为且没有可用性或吞吐量 SLA；中继运营方可能依其自身政策保存运行与滥用防护日志。请勿把“链路加密”理解为匿名服务。

5. 实时语音、视频和屏幕共享

实时媒体仅用于一对一房间，不在多人房间中提供。它使用浏览器 WebRTC；Tailcat 只承载加密的通话信令。STUN 用于发现网络路径，不配置 TURN。通信对端、STUN 服务以及相关网络运营方可能看到你的公网 IP 和连接候选信息。受限网络下，通话可能失败，即使 DERP 上的文字和文件仍可工作。

摄像头、麦克风和屏幕只会在你主动操作并授权后访问。浏览器会显示权限与共享状态；你可以随时拒绝权限或停止共享。移动端切换应用、锁屏或被系统暂停时，房间、传输或通话可能结束；本站不提供后台文件传输或文件断点续传。手机创建多人房间前必须确认保持前台和屏幕唤醒；离开前台会暂停加入与发送，120 秒内未返回会为所有成员关闭房间。

6. 设备上的数据

一对一临时房间密钥默认只在当前页面生命周期内使用。若你主动开启“记住此地址”，私钥会保存在本站来源的 IndexedDB 中，直到你使用“忘记地址”、清除本站数据或浏览器移除它。多人房间始终使用临时地址，不使用已记住的地址。房主浏览器内存保存成员、待审批申请、会话令牌以及最多 100 条或 8 MiB 的近期事件，以便已加入成员在 120 秒内尝试恢复；关闭或刷新房主页会清除这些状态并解散房间。新成员看不到加入前的消息。

在私人一对一房间中，不超过 100 MiB 的文件只有在浏览器提供安全的 Origin Private File System（OPFS），且可信容量估算确认文件大小与安全余量均有足够空间时，才会自动接收至本站来源的临时存储。每个已认证的一对一会话最多自动接收 20 个文件、累计 500 MiB；零字节文件也计一件，达到任一上限后，本会话的后续文件改为手动确认，建立新的已认证会话会重置计数。超过 100 MiB、无法使用 OPFS、无法可靠估算容量或空间不足时，仍须由你确认并在浏览器支持时选择安全的系统保存位置。多人房间文件始终由每位所选接收者分别确认。

OPFS 自动接收不会把文件静默保存到系统下载目录，也不会自动打开、预览或病毒扫描。应用使用随机传输编号而非原始文件名作为 OPFS 路径；完成声明大小与 SHA-256 校验后，须由你点击打开、保存或分享。成功导出、用户取消分享、传输取消、校验失败或写入失败后，应用会删除临时副本；若系统分享因其他错误失败，临时副本会保留以便本地下载或手动删除。应用会在下次启动时清理异常退出留下的传输项；你也可以使用“删除本地副本”或清除本站数据。浏览器仍可能因崩溃、存储故障或平台限制暂时保留数据。

任何通信对端都可以保存其收到的内容。我们无法从对方设备删除消息、录音、文件或截图。

7. 保留、控制与选择

由于没有应用账号或内容数据库，本站通常没有可供导出或删除的账号数据。你可以停止房间、关闭标签页、忘记一对一持久地址、清除浏览器站点数据并撤回媒体权限。多人房主可拒绝申请、移除成员、暂停加入、轮换邀请或关闭房间；无账号模式不能永久封禁某个人。Cloudflare、公共 DERP 或 STUN 提供方掌握的网络记录由各自政策管理。

8. 安全与跨境处理

网络请求和中继可能在你所在国家或地区以外处理。我们采取数据最小化、适用场景下的端到端或逐链路加密、严格浏览器安全策略和无第三方脚本等措施，但无法保证绝对安全，也无法保护已受恶意软件控制的终端或不可信的多人房主。

9. 变更与联系

测试期间，协议、提供商或功能可能变化。重大变更会更新本页日期。使用前请查看当前版本；问题可发送至 abuse@tailcat.app，不要在邮件中附上私钥、完整邀请链接或敏感文件。

English

1. Who provides the service

tailcat.app is an independent, unofficial open-source beta. It is not a Tailscale Inc. product and is not affiliated with or endorsed by Tailscale. For privacy or abuse questions, contact abuse@tailcat.app.

2. Data the app does not create

The site requires no account, creates no user profile, and has no server-side application database for text, files, voice notes, room members, or chat history. We do not provide offline delivery, later server retrieval, cloud backups, content recovery, or malware scanning. Group membership state and the limited recovery buffer exist only in the host browser's memory; a browser may use origin-private temporary storage while receiving an eligible private-room file, as described in section 6.

The initial beta loads no third-party analytics scripts, remote fonts, or remote error reporting. Cloudflare Web Analytics is disabled. Group diagnostics must not record invitations, tokens, Tailcat addresses, nicknames, messages, file names, content, or IP addresses. If operational diagnostics are enabled, they are limited to an anonymous run identifier, member count, latency, error category, byte count, and resource counts.

3. When you open the site

The static site is delivered by Cloudflare Pages. To deliver and protect it, Cloudflare processes ordinary HTTP and security metadata such as IP address, timestamp, request path, User-Agent, TLS information, and cache information. Cloudflare handles edge logs and security records under its service configuration and policies; we do not promise that we can access, export, or delete individual provider records.

A private-room address, or a group room's temporary identifier and join token, is placed in the URL #fragment. A fragment is not sent in an ordinary HTTP request to Cloudflare Pages, and the app removes it from the address bar immediately after reading it. Before removal, it may still be exposed through browser history, the clipboard, extensions, sync features, screenshots, or screen sharing. Rotating a group invitation invalidates its old join token without disconnecting current members.

4. Tailcat transfers

Text, voice notes, control and relayed files use Tailcat WireGuard. When native files are enabled and supported by both peers, file bodies preferentially use reliable WebRTC DataChannels encrypted with DTLS, bypassing the Go network stack. Failed direct setup uses Tailcat/DERP. Incremental hashing still copies bounded chunks into WASM; this is not zero-copy. The trusted group host can read and relay group text, but does not relay file bodies.

Direct files can expose public IP addresses to the peer without requesting camera or microphone access. Interrupted files first query the save result and may restart from zero over the relay once, not resume. Unconfirmed results do not create an automatic duplicate. Partial OPFS files are removed before creating a new random path; picker retries reset the uncommitted transaction. Verified committed files survive lost receipts. Completion receipts exist only in room memory for up to 30 minutes and 256 items, and are cleared when the room ends.

A group host can see nicknames, random member codes, membership, group text, file sizes, and selected recipients, but the coordination protocol does not give the host peer-to-peer file names, voice content, or file content. Any actual recipient can still keep, copy, or forward content received.

Browser connections currently use public Tailcat DERP relays. A relay cannot read the encrypted content it carries, but it processes or observes endpoint IP addresses, connection time, DERP region, transfer volume, and traffic patterns. Public DERP is rate-limited, best-effort beta infrastructure with no uptime or throughput SLA. Relay operators may retain operational and abuse-prevention logs under their own policies. Link encryption does not make this an anonymity service.

5. Live audio, video, and screen sharing

Live media is available only in private one-to-one rooms, not Group Beta. It uses browser WebRTC; Tailcat carries only encrypted call signaling. STUN assists path discovery and no TURN fallback is configured. Your peer, the STUN service, and relevant network operators may see your public IP address and connection candidates. Calls can fail on restrictive networks even when DERP-relayed text and files still work.

Camera, microphone, and display access begins only after your action and browser permission. Your browser shows permission and sharing state, and you can deny permission or stop sharing at any time. On mobile, changing apps, locking the device, or operating-system suspension may end a room, transfer, or call; the site provides neither background file transfer nor resumable files. Before hosting a group on a phone, you must acknowledge that the page and screen need to stay in the foreground. Backgrounding pauses joins and sends; failure to return within 120 seconds ends the room for everyone.

6. Data on your device

A private room uses an ephemeral key for the current page lifetime by default. If you enable “remember this address,” its private key is stored in IndexedDB for this origin until you choose “forget address,” clear site data, or the browser removes it. Group rooms always use an ephemeral address and never reuse a remembered address. The host browser keeps members, pending requests, session tokens, and up to 100 recent events or 8 MiB in memory so an existing member can attempt recovery within 120 seconds. Closing or refreshing the host page clears that state and ends the room. New members cannot see messages from before they joined.

In a private one-to-one room, a file of up to and including 100 MiB is automatically received into this origin's temporary storage only when the browser provides a safe Origin Private File System (OPFS) and a trustworthy capacity estimate confirms room for the file plus the safety margin. Each authenticated private session can auto-receive at most 20 files and 500 MiB in total; a zero-byte file counts as one, reaching either limit makes later files in that session manual, and a new authenticated session resets the counters. A file over 100 MiB, or one for which OPFS, reliable estimation, or sufficient space is unavailable, still requires your approval and a safe system destination where the browser supports one. Every group-room file always requires separate approval from each selected recipient.

OPFS automatic receive does not silently save a file to the system Downloads folder, and the app never automatically opens, previews, or malware-scans it. The app uses a random transfer identifier rather than the offered file name as its OPFS path. After declared-size and SHA-256 verification, you must click to open, save, or share the file. The app deletes the temporary copy after successful export, user-cancelled sharing, transfer cancellation, verification failure, or write failure. If system sharing fails for another reason, the copy remains available for local download or manual deletion. The app cleans abandoned transfer entries on its next start and offers “delete local copy”; clearing site data also removes it. A crash, storage fault, or platform limitation may delay cleanup.

Any peer can keep content they receive. We cannot delete messages, recordings, files, or screenshots from another person's device.

7. Retention, controls, and choices

Because there is no application account or content database, the site normally has no account dataset to export or erase. You can stop a room, close the tab, forget a private-room persistent address, clear browser site data, and revoke media permissions. A group host can reject a request, remove a member, pause joining, rotate the invitation, or close the room; accountless operation cannot permanently ban a person. Network records held by Cloudflare, public DERP, or STUN providers are governed by those providers' policies.

8. Security and international processing

Network requests and relays may be processed outside your country or region. We use data minimization, end-to-end or per-link encryption where applicable, strict browser security policy, and no third-party scripts, but no system is perfectly secure and we cannot protect a compromised endpoint or an untrusted group host.

9. Changes and contact

The protocol, providers, or features may change during beta. Material changes will update the date on this page. Review the current version before use. Contact abuse@tailcat.app, but never email a private key, full invitation link, or sensitive file.
